# 정승준 · Seung Joon Jeong

전자공학을 전공하는 정승준입니다. 로봇 제어, 딥러닝 기반 소음제어, AI 에이전트 개발 프로젝트에서 프로그램 구현과 장비·서비스 연동을 담당했습니다.

## 대표 프로젝트

### RGB-D 기반 로봇 인식·접근 제어

담당: 물체 위치 추정과 이동로봇 제어 연동

카메라에서 찾은 물체의 위치를 로봇이 사용할 수 있는 좌표로 바꾸고, 이동로봇의 접근 동작과 연결했습니다.

- 데이터 수집·라벨링과 YOLO 학습을 진행하고, RGB-D 깊이 정보로 물체의 3D 위치를 추정했습니다.
- ROS 2 TF로 카메라 좌표를 로봇 기준 좌표로 변환하고, 위치 조회와 접근 제어를 연동했습니다.
- 목표물을 놓치거나 탐지 정보가 오래되면 정지하도록 처리하고, 갱신된 위치에 맞춰 다시 정렬하도록 구성했습니다.

사용 기술: Python, ROS 2, YOLO, OpenCV, RGB-D, TF

### DeepANC — 딥러닝 기반 능동소음제어

담당: 모델 설계·학습과 추론 코드 구현

덕트 내 소음을 줄이기 위한 딥러닝 모델을 개발하고, 연속 오디오 입력을 처리하는 추론 경로를 구현했습니다.

- PyTorch 모델의 학습 코드와 연속 오디오를 처리하는 추론 코드를 구현했습니다.
- 오디오 처리 구간 사이에서 모델 상태를 유지하고, ONNX Runtime으로 모델을 실행하도록 구성했습니다.
- Jetson AGX Orin에서 추론 계산시간을 측정하고, 실행 환경에 따른 동작을 확인했습니다.

사용 기술: Python, PyTorch, ONNX Runtime, Jetson AGX Orin

### RE:BORN — 폐업 절차 안내 서비스

담당: AI 에이전트 개발 · 팀 프로젝트 진행 중

폐업을 준비하는 소상공인의 상황과 공식 절차 자료를 바탕으로, 다음에 해야 할 일을 안내하는 서비스를 팀으로 개발하고 있습니다.

- LangGraph로 절차 조회, 정보 분석, 행동 판단을 연결하고, 판단 결과를 별도로 검수하는 흐름을 개발했습니다.
- 새 입력이 기존 사실과 충돌하거나 판단 근거가 부족한 경우를 구분하고, 검수를 통과한 판단 결과만 반환하도록 구현했습니다.
- 백엔드 팀과 주고받을 데이터와 저장할 내용을 맞추고, 검수된 절차 자료와 단계별 순서를 다음 행동 판단에 연결했습니다.

사용 기술: Python, LangGraph, Pydantic, LLM

## 추가 구현 경험

- AI 에이전트 행동 예측: 대화·세션 로그를 바탕으로 다음 행동을 예측하고, 모델 조합과 가중치 압축을 실험했습니다.
- 임베디드 시스템: TI C2000에서 GPIO, 인터럽트, 타이머, ADC, PWM을 다루는 제어 프로그램을 작성했습니다.
- DSP 오디오 처리: TI SYS/BIOS와 EDMA를 이용한 오디오 입출력 및 버퍼 처리 실습을 진행했습니다.
